# Аудит SELIGER от 20 октября 2026 — выполненные исправления

Проверены замечания по `main`; источником был предоставленный пользователем отчёт по GitHub.

## Исправлено

1. **Офлайн-кеш JSON:** `sw.js` хранит одну запись по каноническому пути независимо от `?ts` / `?v`. Онлайн — запрос нового файла, при ошибке — последняя сохранённая версия. Обновлён номер кеша для перехода со старой схемы. Не кэширует картографические тайлы.
2. **Свежесть погоды при возвращении:** `app.js` обрабатывает `visibilitychange`, `pageshow` и `focus`. Проверяет, сколько прошло времени; при устаревании убирает обозначение «Свежий запрос», показывает предупреждение и пытается выполнить новый запрос. Старое `current` не используется как измерение текущего часа.
3. **Пропуски данных на графике:** `chart-core.js` не включает `null`, `undefined` и пустые значения в пределы оси, не рисует отсутствующие столбцы. `tests/chart-nulls.cjs` проверяет это и включён в CI.
4. **Полный фильтр карты:** `map.js` скрывает географические ориентиры, не подходящие к выбранной рыбе и сезонности; кнопка «Показать все» учитывает видимые результаты. `tests/mobile.cjs` проверяет слой.
5. **Документация:** `README.md` полностью пересмотрен под пять актуальных разделов, встроенные графики, реальные тесты и ограничения PWA.

## Не исправлено полностью / причины

- **Подложка карты офлайн:** внешние тайлы OSM не сохраняются, при отсутствии связи основной картографический фон недоступен; ссылки на OSM требуют подключения. Для полной офлайн-карты нужна отдельная законная и технически проверенная картографическая сборка.
- **GPS причала «Ладья»:** пользователь подтвердил причал на базе, но точные координаты причала не установлены. Нельзя подставлять центр Бараново как точку спуска или автоматически строить водный маршрут.
- **Совместная батиметрия:** карта ЭтоМесто открывается отдельно; условия лицензии на совмещение глубин с рыболовными точками неизвестны.
- **Реальный iPhone:** автоматические Chromium/WebKit тесты не равны полноценному тесту физического iPhone; его ещё нужно выполнить пользователю.

## Реальная регрессия

В репозитории уже существовали `tests/mobile.cjs`, `tests/live-audit.cjs`, независимые Chromium/WebKit QA и GitHub Actions. Утверждение исходного аудита об отсутствии Playwright и UI тестов относится к неполной проверке репозитория и не соответствует текущей структуре. Новые тесты дополнили существующий контур.

При любой публикации важно проверять **последний** запуск GitHub Actions, а не считать успех прошлого запуска доказательством новой версии.
