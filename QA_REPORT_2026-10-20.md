# SELIGER — независимый аудит мобильной версии

Дата: 20 октября 2026. Проверялся публичный GitHub Pages: https://dalesc219-netizen.github.io/SELIGER/

## Два независимых тестировщика

Оба теста запущены на **разных виртуальных машинах GitHub Actions**, каждый со своей браузерной сессией и отдельным архивом артефактов.

| Поток | Движок | Портретный экран | Альбомный экран | Результат |
|---|---|---|---|---|
| Агент 1: погода, графики и переходы | Chromium | 402 × 874 | 874 × 402 | 24/24 |
| Агент 2: iPhone Safari UX | WebKit | 402 × 874 | 874 × 402 | 24/24 |

Общий результат: **48/48 автоматических проверок успешно**, без ошибок JavaScript и горизонтального переполнения страницы.

[Запуск независимых тестов](https://github.com/dalesc219-netizen/SELIGER/actions/runs/39388055219). В GitHub Actions доступны по отдельности артефакты `seliger-agent-1-chromium` и `seliger-agent-2-webkit`: `report.json` и полноразмерные PNG-скриншоты каждого режима.

## Проверенные сценарии

1. Публичный сайт отвечает HTTP 200.
2. Резервный прогноз показывает числовые значения. Во время проверки строка состояния сообщала «Сохранённый прогноз · 20.10, 10:19 МСК».
3. Верхняя компактная панель не теряет температуру, ветер, осадки и давление при переключении экранов.
4. Пять основных графиков не пустые: подтверждена фактическая отрисовка на canvas.
5. Переключаются диапазоны, работает переход от иконки верхней панели к соответствующему графику.
6. Доступны дневник уловов и раздел отчётов.
7. На проверенных размерах отсутствует горизонтальное переполнение.
8. Favicon SVG и иконки для домашнего экрана опубликованы.

## Исправления по результатам подготовки и аудита

- Добавлен узнаваемый образ Селигера: упрощённый силуэт Ниловой пустыни и две линии волн. Отдельные PNG для favicon 32×32 и iPhone 180×180; `manifest.webmanifest`.
- Обновлена шапка SELIGER с фирменным знаком.
- Сохранены прежние доработки мобильного интерфейса: дополнительный верхний отступ для Dynamic Island, фиксированная мини-панель погодных показателей и подсветка активного графика.
- Создан воспроизводимый аудит опубликованного сайта, а не только локальная проверка проекта.
- Два независимых задания CI, которые можно запускать повторно из GitHub Actions.

## Что тесты НЕ доказывают

- Эмулятор WebKit не равен реальному Safari на iPhone 17 Pro: точное положение Dynamic Island, системные панели и жесты нужно проверить на устройстве.
- Проверка прозрачности canvas доказывает, что график нарисован, но не подтверждает научную точность индекса клёва.
- Картографические данные и глубины в рамках этого релиза ещё не реализованы.
- Прямой источник данных Open-Meteo в наблюдавшихся прогонах не заменил сохранённый прогноз; нужно отдельно контролировать доступность сети и возраст резервного прогноза.
- Формальное отсутствие UI-ошибок не исключает субъективных неудобств на воде (яркость, читаемость на солнце, управление мокрыми руками).

## Ближайшие рекомендации

1. На реальном iPhone проверить закреплённую панель в Safari и при добавлении приложения на экран «Домой».
2. Если прогноз был сохранён более 6 часов назад, показывать заметное предупреждение о давности, чтобы не спутать его со свежей погодой.
3. Улучшить читаемость графиков на солнце и подписать источник/время прогноза непосредственно возле графиков.
4. Добавить импорт дневника и офлайн-работу; сейчас экспорт JSON не обеспечивает автоматического восстановления.
