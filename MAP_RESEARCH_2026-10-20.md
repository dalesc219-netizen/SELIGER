# SELIGER — карта и источники глубин, аудит на 20.10.2026

## Этап А. Реализация карты
- Удалена графическая отметка «СЕЙЧАС» во всех графиках.
- В нижней панели добавлена пятая вкладка «Карта».
- На карте используется Leaflet 1.9.4 и картографическая подложка OpenStreetMap (© OpenStreetMap contributors). Для аварийного режима предусмотрено открытие OSM во встроенном окне.
- Добавлены фильтры по рыбе, переход к сообщению и кнопка GPS (только по явному нажатию и разрешению пользователя).
- Только подтверждённые географические ориентиры; метки не обозначают координаты вылова. Полупрозрачные круги отражают **приблизительный радиус привязки**, а не точность GPS.
- `data/map_points.json` хранит обоснование каждого ориентира, дату и ссылку на первоисточник.

## Этап B. Разбор Русфишинга
Создан `scan_rusfishing.py` — поэтапный индексатор открытой темы, учитывает robots.txt, ограничивает частоту запросов, извлекает дату, вид рыбы и упоминание места. Он сохраняет только **кандидатов**, а не GPS-точки; на карту они автоматически не переносятся.

20 октября 2026 GitHub Actions запустил индексатор. Первый запрос темы на стр. 248 получил **HTTP 403 Forbidden**, поэтому охват автоматического индекса — **0/248 страниц**. Нельзя считать весь архив обработанным. Автоматические повторные запросы по расписанию остановлены; ручная проверка доступных через поисковую индексацию постов продолжается. Состояние фиксируется в `data/forum_scan_state.json` и отображается на карте.

## Этап C. Батиметрия
| Источник | Что найдено | Возможность встроить вместе с маркерами |
|---|---|---|
| [ЭтоМесто — карта глубин Селигера](https://etomesto.com/map-tver_seliger-glubiny/) | Историческая карта 2001 года, с изобатами из материалов 1970-х | Онлайн-просмотр на оригинальном сайте доступен. **Лицензия на перепубликацию и смешивание со своим слоем не подтверждена.** |
| [ЭтоМесто — MBTiles](https://etomesto.com/karta7522/) | Привязанный MBTiles около 47.74 МБ, персональное некоммерческое использование для указанных целей | Нельзя размещать у себя без проверки разрешения; пользователь может просматривать на стороне источника |
| [Garmin/Навионикс — Web API](https://developer.garmin.com/marine-charts/web/) | Standard: бесплатный встроенный картографический просмотрщик с ключом | У Standard **запрещены наложенные собственные маркеры**; Enhanced с оверлеями платный. Ключ не получен |
| [«Лодочка» — Селигер](https://lapti.pro/boatnavigator/maps/tver_seliger_oz) | Полноценный коммерческий набор глубин, заявлена детализация ~75% | 1197 руб., только приложение «Лодочка»; не лицензировано для встраивания |

**Состояние:** построенная в SELIGER карта содержит реальные берега и ориентиры, но не рисует самодельные изобаты поверх маркеров. Вкладка предлагает отдельный, загружаемый только после нажатия пользователя, просмотр исторической карты глубин через публичный iframe издателя ЭтоМесто; также всегда доступна прямая ссылка на первоисточник. Внешний просмотрщик может блокироваться поставщиком или браузером; успешная загрузка конкретного растра не подтверждена. Прямое наложение собственных маркеров на исторические глубины без лицензии остаётся не реализованным. Следующий шаг для полноценного совместного слоя — получить разрешение правообладателя на размещение геопривязанного растра/тайлов или найти подтверждённый свободно лицензированный набор для Селигера.

## Проверки
GitHub Actions `Verify SELIGER` проверяет синтаксис `app.js`, `mobile.js`, **`map.js`**, а также основные файлы и `update_water.py`. Mobile browser tests проверяет вкладку «Карта» в portrait/landscape, две геопривязанные карточки и фильтры. Для физического Safari на iPhone потребуется отдельная приёмка.

## Безопасность
Карта и исторические глубины не являются официальной судовой навигацией. Метки с радиусами неопределённости предназначены для анализа отчётов, а не для подхода лодкой к точке.

## Дополнение: мобильный офлайн-режим, 20.10.2026
В SELIGER добавлен сервис-воркер sw.js для сохранения файлов самого приложения и JSON с погодой и отчётами. При наличии сети применяется свежая версия; при её отсутствии используются ранее загруженные файлы. Картографические тайлы OSM и сторонние карты глубин не загружаются заранее и не гарантируются офлайн. Для первоначального открытия требуется интернет. Сентябрьское обсуждение коротких выходов судака включено в раздел отчётов как наблюдение без геопривязки. Полный архив форума по-прежнему недоступен автоматическому сборщику из-за HTTP 403.
